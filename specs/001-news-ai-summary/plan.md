# Implementation Plan: 新闻AI总结系统

**Branch**: `001-news-ai-summary` | **Date**: 2026-04-12 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/001-news-ai-summary/spec.md`

## Summary

新闻AI总结系统是一个基于 Miniflux RSS 的工具，通过 AI 分析财经新闻并生成 Markdown 格式的总结报告。支持 CLI 和桌面 GUI 双模式，核心功能包括：多 Feed 选择、交互式界面、OpenAI/Anthropic 双 AI 支持、进度可视化。

## Technical Context

**Language/Version**: Python 3.11+
**Primary Dependencies**: Typer (CLI), Rich (UI), PyQt6/PySide6 (Desktop GUI), miniflux SDK, openai, anthropic, pyyaml, pydantic, loguru, httpx
**Storage**: SQLite (optional, for history caching)
**Testing**: pytest, pytest-asyncio, ruff (linting), mypy (type checking)
**Target Platform**: Windows/macOS/Linux (CLI + Desktop)
**Project Type**: CLI tool + Desktop GUI application
**Performance Goals**: Feed fetch <2s, News fetch <5s, AI summary <30s
**Constraints**: Max 100 news items per summary, 4096 token limit, 7-day news retention
**Scale/Scope**: 8 configured feeds, single-user operation initially

### Data Models

```python
# src/models.py
@dataclass
class Feed:
    id: int
    title: str
    category: str = ""
    enabled: bool = True

@dataclass
class Entry:
    id: int
    title: str
    url: str
    published_at: datetime
    summary: str
    content: Optional[str] = None
    feed_id: int = 0
    feed_title: str = ""

@dataclass
class Highlight:
    title: str
    source: str
    summary: str
    importance: str = "medium"

@dataclass
class SummarizeResult:
    summary: str
    highlights: list[Highlight]
    keywords: list[str]
    sentiment: str
    generated_at: datetime = field(default_factory=datetime.now)
```

### AI Client Factory

```python
class AIClientFactory:
    @staticmethod
    def create(provider: str, config: dict) -> AIClient:
        if provider == "openai":
            return OpenAIClient(config)
        elif provider == "anthropic":
            return AnthropicClient(config)
        else:
            raise ValueError(f"Unknown AI provider: {provider}")
```

## Risk Assessment

| Risk | Impact | Probability | Mitigation |
|------|--------|------------|------------|
| Miniflux API unavailable | High | Low | Graceful error with user-friendly message |
| AI API rate limit | Medium | Medium | Retry with exponential backoff (3 attempts) |
| Network timeout | Medium | Medium | 30s timeout, retry logic |
| Token limit exceeded | Low | Low | Cap at 100 items, truncate if needed |
